# Captain Chess

A single-player chess campaign about raising captains and heirs across an ancient world.

[Captain Chess at Burrito’s Labs](https://captainchess.burritoslabs.com/)

## Technology

JavaScript, SVG, CSS, Web Workers and browser storage.

## Architecture

The campaign extends a chess board with commanders, objectives and consequences that carry into later battles. Browser rendering presents board and map state while game rules determine legal actions.

## Product behavior

Campaigns save in the browser. Players can export a run or download for offline play in supported browsers.
